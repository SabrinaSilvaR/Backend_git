# Skill: Spec — Intake

Guided interview that helps anyone (technical or not) turn a rough idea into a structured
brief ready for `/spec-propose`. Optional on-ramp to the spec loop.

## When to use

When the user gives a vague or high-level request ("quiero un módulo para registrar profesores",
"necesito validar que las notas no superen 7.0") and you need to clarify scope before proposing specs.

## Interview loop

1. **Acknowledge and summarize:** Mirror what the user said in plain, clear language.
2. **Clarify missing requirements:** Ask 1–3 short, concrete questions (who uses it, what happens on invalid data, what are the expected outputs).
3. **Draft the Idea Brief:** Save under `specs/changes/<tentative-id>/idea.md` using `.ai/templates/idea.template.md`.
4. **Handoff:** Suggest moving to `/spec-propose`.
